# 编码与评价手册

## 一、定量指标

| 指标 | 变量 | 算法/范围 |
|---|---|---|
| 文化理解前测 | pre_culture | 1—5 |
| 文化理解后测 | post_culture | 1—5 |
| 理解增量 | culture_gain | post-pre，-4至4 |
| 任务正确 | task_correct | 0/1 |
| 完成时长 | completion_sec | 秒，保留正值 |
| 相关性 | relevance | 1—5 |
| 文化清晰度 | cultural_clarity | 1—5 |
| 语言适配 | language_accessibility | 1—5 |
| 易用性 | usability | 1—5 |
| 信任 | trust | 1—5 |
| 再次使用意愿 | reuse_intent | 1—5 |

主比较：智语桥组与常规检索组的文化理解增量、任务正确率和完成时长。满意度指标仅描述智语桥组，不与未使用工具的对照组强行比较。

## 二、质性一级编码

| 代码 | 定义 | 示例边界 |
|---|---|---|
| LANG_LEVEL | 语言难度、词汇、句法或拼音负担 | 不含纯文化事实错误 |
| CULTURE_CONTEXT | 历史、礼仪、方言、隐含语境解释需求 | 与单纯翻译区分 |
| SCENARIO_TASK | 城市生活或课堂真实任务 | “想要更多内容”但无场景不编码 |
| MULTILINGUAL | 英语、葡语等跨语种支持 | 拼音单独记为LANG_LEVEL |
| SOURCE_TRUST | 来源、准确性、AI幻觉与核实 | 界面易用不编码 |
| TEACHER_CONTROL | 教师编辑、审核、导出与课堂控制 | 学习者一般信任不编码 |
| UX_ACCESS | 页面操作、速度、设备与无障碍 | 内容问题不编码 |
| SHARE_SPREAD | 分享、传播、推荐与社交表达 | 再次个人使用不等同分享 |

## 三、双人编码规则

1. 两名编码者先共同编码2份练习文本并修订定义。
2. 独立编码不少于20%的正式文本，计算简单一致率和Cohen's kappa。
3. kappa低于0.60时不得直接发布主题频数，须回到定义和冲突案例复核。
4. 引语去除姓名、学校、国籍与可识别细节；转述不得改变原意。

## 四、结论强度

- 合成验证数据：只能写“流程可运行”“在设定参数下呈现预期差异”，不能写“实际用户显著提升”。
- 小样本真实试测：写“初步观察”“受访者反馈”，避免总体推广。
- 达到预注册样本与质量标准后：可报告效应量和置信区间，并说明局限。
