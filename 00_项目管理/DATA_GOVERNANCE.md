# 数据真实性与隐私治理

## 1. 证据分级

| 类型 | 定义 | 可否用于正式结论 | 标识 |
|---|---|---|---|
| A 真实一手数据 | 已取得同意的问卷、访谈、观察、系统日志与实拍资料 | 可以 | REAL |
| B 真实公开数据 | 政府、国际组织、标准、论文等可追溯资料 | 可以，须引用 | PUBLIC |
| C 合成验证数据 | 为调试问卷、脚本、统计图和报告模板而生成 | 不得伪装为真实样本 | SYNTHETIC |
| D 示例内容 | 教学示例、虚拟角色、演示回答 | 仅作说明 | DEMO |

## 2. 强制规则

1. 原始联系人、手机号、邮箱和语音记录只放在 `04_原始数据_受限`，不进入公开仓库或匿名材料。
2. 分析数据使用随机编号；删除姓名、精确地址、账号和可识别自由文本。
3. 合成数据文件名、元数据列和图表脚注均明确标注 `SYNTHETIC`；正式数据导入后另存为 `REAL`。
4. 报告不得写“已访谈/已覆盖/显著提升”等无法由现有证据支持的完成式结论。
5. 引用保留标题、机构、发布日期、访问日期和链接；不复制大段原文。
6. AI输出必须经过团队人工审核，文化事实和政策解释以权威来源为准。
7. 研究对象如包含未成年人，必须另行取得监护人同意，本项目默认不招募未成年人。

## 3. 最小同意口径

- 说明研究目的、预计时长、记录方式、数据用途、匿名处理和退出权利。
- 参与完全自愿；拒绝或退出不产生不利后果。
- 录音、录像、肖像公开必须分别征得明确同意，不得以问卷同意替代肖像授权。
- 数据仅由项目团队与指导教师在项目目的范围内使用。

## 4. 正式替换检查

- [ ] 清除所有 `SYNTHETIC` 行并导入真实匿名数据，或在材料中明确其仅为方法演示。
- [ ] 核对样本量、日期、场地、人员、照片与日志能相互印证。
- [ ] 核对所有百分比的分母、缺失值处理和图表注释。
- [ ] 匿名版再次搜索姓名、学号、手机号、学院、教师姓名和文件属性。
- [ ] 由指导教师审阅结论强度、伦理表述和对外传播内容。
