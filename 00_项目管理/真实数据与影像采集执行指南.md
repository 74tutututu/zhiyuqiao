## 四、统一隐私和编号规则

### 4.1 禁止写入公开数据的内容

问卷、访谈和任务测试文件不得出现：

- 姓名；
- 手机号、邮箱、微信号；
- 学号、证件号、护照号；
- 精确住址、宿舍号；
- 可直接识别个人的自由文本。

### 4.2 编号规则

| 类型 | 编号格式 | 示例 |
|---|---|---|
| 学习者问卷 | `REAL-三位数字` | `REAL-001` |
| 学习者访谈 | `REAL-L-三位数字` | `REAL-L-001` |
| 教师/志愿者访谈 | `REAL-T-三位数字` | `REAL-T-001` |
| 智语桥组任务测试 | `TASK-Z-三位数字` | `TASK-Z-001` |
| 常规检索组任务测试 | `TASK-C-三位数字` | `TASK-C-001` |
| 知情同意记录 | `CONSENT-对应编号` | `CONSENT-REAL-L-001` |

编号必须连续，不要重复，不要把参与者姓名缩写写进编号。

同一个学习者同时参加问卷和任务测试时，可以在任务记录内部填写其问卷编号，例如 `source_questionnaire_id: REAL-008`；对外匿名数据只保留编号，不保留联系方式。

联系方式只可另存于受限的邀请台账，不要写进问卷答案、访谈正文或任务测试记录。提交给我分析前，可以删除已不需要的联系信息。

## 五、第一项：Markdown问卷

### 5.1 招募目标

- 最低获得60份有效问卷；
- 建议发放70—80份；
- 对象为年满18周岁的国际中文学习者；
- 尽量覆盖不同中文水平、母语和是否到过上海的经历；
- 不要只邀请团队熟悉、观点相近的人。

### 5.2 发放方式

1. 打开 `03_调研设计/01A_国际中文学习者问卷_直接发送版.md`。
2. 复制全文，通过微信、邮件、群聊或其他渠道发给参与者。
3. 同时发送下面这句话：

> 请复制整份问卷，在每个“答案：”后填写，再把完整内容发回。问卷匿名，不要填写姓名、手机号或邮箱。如果没有试用智语桥，请按说明填写“未试用/不适用”。

4. 记录发送时间和收到回复的时间，用于识别明显过快作答。
5. 收到回复后，不要修改参与者原话；只分配匿名编号并保存。

### 5.3 问卷文件命名和保存

保存目录：

`智语桥/04_原始数据_受限/真实调研/问卷回复/`

命名示例：

- 第一份：`REAL-001.md`
- 第二份：`REAL-002.md`
- 第六十份：`REAL-060.md`

文件内容必须保存参与者返回的完整问卷，不要只摘抄部分答案。

如需要保留回收时间，可在文件最上方增加：

```text
respondent_id: REAL-001
sent_at: 2026-08-28 14:10
returned_at: 2026-08-28 14:22
collector: 徐千顺
```

### 5.4 单份问卷质量检查

每收到一份立即检查：

- [ ] Q0确认已满18周岁且自愿参加；
- [ ] Q1同意匿名使用答案；
- [ ] 主要问题没有大面积空白；
- [ ] 多选题没有明显超过规定数量；
- [ ] 未试用者正确填写“未试用/不适用”；
- [ ] 没有姓名、手机号、邮箱等个人信息；
- [ ] 回答不是明显复制同一个模板答案；
- [ ] 开放题不是无意义字符；
- [ ] 作答用时不是明显异常。

质量标记规则：

- `PASS`：同意有效、主要题目完整、回答可信；
- `REVIEW`：少量缺失、用时过短或答案模式异常，需要第二人复核；
- `EXCLUDE`：不同意、未满18周岁、大量空白或明显无效。

不要删除无效文件。在文件最上方添加 `quality_flag: EXCLUDE` 和简短原因，分析时由我排除。

### 5.5 问卷阶段完成标准

- [ ] 至少60份标记为 `PASS`；
- [ ] 文件编号连续；
- [ ] 每份文件均为完整原始回复；
- [ ] 受限目录中没有把联系方式混入答案；
- [ ] 至少两名项目成员复核了 `REVIEW` 记录。

## 六、第二项：真实访谈

### 6.1 招募目标

- 学习者访谈至少8人，建议10人；
- 教师或中文教学志愿者访谈至少3人，建议4人；
- 学习者可从问卷Q2选择“愿意”的参与者中邀请；
- 教师访谈应尽量覆盖不同教学经验或教学对象；
- 访谈可以当面、语音、视频或即时文字聊天完成。

### 6.2 什么才算一次有效访谈

必须同时满足：

- 时长原则上15—25分钟；
- 访谈人员按照模板逐题交流；
- 根据回答至少进行一次有效追问；
- 保留受访者原意和具有代表性的原话；
- 完成知情同意和匿名引用确认；
- 不能只是把访谈模板发给对方后等待自行填写。

### 6.3 访谈执行顺序

1. 给参与者介绍项目目的、预计时间、匿名方式和退出权利。
2. 确认年满18周岁、自愿参加、是否允许匿名引用。
3. 分别确认录音、照片和视频授权；不同意录音不影响访谈。
4. 给学习者使用学习者模板，给教师或志愿者使用教师模板。
5. 主持人提问；记录人员记录回答和追问。
6. 结束时再次确认哪些原话可以匿名用于报告。
7. 当天完成文件命名、保存和备份。

### 6.4 学习者访谈文件

使用：`03_调研设计/02A_学习者访谈_直接执行版.md`

保存目录：

`智语桥/04_原始数据_受限/真实调研/访谈记录/`

文件名：

- `REAL-L-001.md`
- `REAL-L-002.md`
- 依次编号。

如获得录音授权，录音文件使用同一编号：

- `REAL-L-001.m4a`
- `REAL-L-001.mp3`

### 6.5 教师或志愿者访谈文件

使用：`03_调研设计/02B_教师访谈_直接执行版.md`

文件名：

- `REAL-T-001.md`
- `REAL-T-002.md`
- 依次编号。

如获得录音授权：

- `REAL-T-001.m4a`
- `REAL-T-001.mp3`

### 6.6 访谈质量检查

每份访谈完成后检查：

- [ ] 有明确参与编号、日期、方式、访谈人员和时长；
- [ ] 有自愿参加、匿名引用和录音/影像授权记录；
- [ ] 每个核心问题均有回答；
- [ ] 至少有一次有效追问；
- [ ] 代表性原话没有被改写成团队希望看到的结论；
- [ ] 未试用智语桥者如实写“未试用”；
- [ ] 文件名、正文和录音不包含姓名或联系方式；
- [ ] 第二名成员已检查明显遗漏。

### 6.7 访谈阶段完成标准

- [ ] 至少8份有效学习者访谈；
- [ ] 至少3份有效教师/志愿者访谈；
- [ ] 每份均有匿名引用授权；
- [ ] 录音与文字记录编号一致；
- [ ] 未授权公开的照片、视频和引语已单独标记。

## 七、第三项：任务对照测试

### 7.1 测试目的

比较两种工具在同一海派文化任务中的表现：

- 智语桥组：只能使用智语桥；
- 常规检索组：只能使用普通浏览器或搜索引擎；
- 两组使用相同任务、相同时限和相同评分规则；
- 主要比较文化理解增量、任务正确、完成时长和求助次数；
- 智语桥组另外填写相关性、语言适配、文化清晰度、易用性和信任评价。

### 7.2 参与者和分组

- 从已完成问卷的学习者中邀请30人；
- 智语桥组至少15人，常规检索组至少15人；
- 尽量让两组中文水平分布相近；
- 可先按HSK水平排序，再在同一水平内交替分配到两组；
- 不允许参与者自己选择更喜欢的组；
- 测试前不要告诉参与者项目希望哪组表现更好。

分组编号：

- 智语桥组：`TASK-Z-001`、`TASK-Z-002`……
- 常规检索组：`TASK-C-001`、`TASK-C-002`……

### 7.3 测试环境

- [ ] 两组设备类型尽量一致；
- [ ] 网络条件尽量一致；
- [ ] 两组总时限一致；
- [ ] 主持人的提示语一致；
- [ ] 智语桥组测试前确认系统正常；
- [ ] 常规检索组不得使用智语桥；
- [ ] 不记录参与者搜索账号、浏览历史或个人信息；
- [ ] 每名参与者单独完成，避免互相抄答案。

### 7.4 测试统一话术

主持人对两组都读：

> 接下来进行一项上海文化学习任务。请先独立完成前测，然后使用分配给您的工具查找和学习信息，最后完成后测。您可以随时退出。我们记录答题、用时和求助次数，不评价您的个人中文能力。

智语桥组补充：

> 学习阶段请只使用智语桥，可以正常提问和追问。

常规检索组补充：

> 学习阶段请只使用普通浏览器或搜索引擎，可以打开搜索结果网页，但不要使用智语桥。

### 7.5 统一测试流程

#### A. 前测，约3分钟

1. 你目前对“外滩历史建筑与陆家嘴现代天际线”的理解程度是多少？填写1—5分。  
   `pre_culture: ___`
2. 判断题：“外滩历史建筑和陆家嘴天际线主要形成于同一历史时期。”  
   正确答案：错误。
3. 用不超过30个汉字写出外滩与陆家嘴的一个差异。  
   评分：
   - 0分：无关、空白或明显错误；
   - 1分：提到外观差异但没有历史或功能信息；
   - 2分：正确指出历史建筑与现代城市天际线、历史延续与现代发展等核心差异。

#### B. 工具学习，统一8分钟

请参与者使用分配工具了解：

- 外滩与陆家嘴分别体现怎样的城市发展阶段；
- 如何用适合国际中文学习者的语言解释两者差异；
- 哪些信息需要核验来源。

记录：

- 学习开始时间；
- 学习结束时间；
- 主动求助次数；
- 系统或网络错误；
- 是否超时。

#### C. 后测，约5分钟

1. 现在对这一主题的理解程度是多少？填写1—5分。  
   `post_culture: ___`
2. 选择题：外滩与陆家嘴放在同一文化任务中，最适合说明什么？  
   A. 上海只有西式建筑  
   B. 上海城市历史延续与现代发展并存  
   C. 两地完全没有文化联系  
   正确答案：B。
3. 请用40—80个汉字向HSK2学习者解释外滩与陆家嘴的差异，并说明一项应当核验的来源。  
   评分0—3分：
   - 1分：文化事实和对比基本正确；
   - 1分：语言简明，适合初中级学习者；
   - 1分：提出官方页面、博物馆、权威出版物等可核验来源。

任务成功判定：选择题正确，且开放题得分至少2分，记 `task_correct: 1`；否则记 `task_correct: 0`。

#### D. 智语桥组体验评价，约2分钟

智语桥组填写1—5分：

- 回答相关性 `relevance`；
- 文化解释清晰度 `cultural_clarity`；
- 语言难度适配 `language_accessibility`；
- 页面易用性 `usability`；
- 来源和审核提示带来的信任 `trust`；
- 再次使用意愿 `reuse_intent`。

常规检索组这些字段留空或写 `NA`，不要编造智语桥体验分。

### 7.6 每名参与者的记录文件

保存目录：

`智语桥/04_原始数据_受限/真实调研/任务测试记录/`

文件名：

- 智语桥组：`TASK-Z-001.md`
- 常规检索组：`TASK-C-001.md`

每个文件复制下面模板填写：

```text
# 智语桥任务对照测试单人记录

task_record_id:
source_questionnaire_id:
consent: 同意/不同意
age_18_plus: 是/否
test_date:
group: 智语桥组/常规检索组
hsk_level:
observer:

pre_culture:
pre_judgement_answer:
pre_open_answer:
pre_open_score_0_2:

learning_start_time:
learning_end_time:
completion_sec:
help_count:
system_or_network_error:

post_culture:
post_choice_answer:
post_open_answer:
post_open_score_0_3:
task_correct_0_1:
culture_gain:

relevance_1_5_or_NA:
cultural_clarity_1_5_or_NA:
language_accessibility_1_5_or_NA:
```

计算规则：

- `completion_sec`：学习开始到提交后测的秒数；
- `culture_gain`：`post_culture - pre_culture`；
- `help_count`：参与者要求主持人解释操作或问题的次数；
- 主持人只能解释操作，不得提示文化题答案。

### 7.7 任务测试质量检查

- [ ] 两组人数均不少于15；
- [ ] 两组HSK水平分布没有明显失衡；
- [ ] 每人完成前测、学习和后测；
- [ ] 时间记录合理且单位统一为秒；
- [ ] 开放题按统一规则评分；
- [ ] 至少20%的开放题由第二人独立复核；
- [ ] 常规检索组未填写智语桥体验分；
- [ ] 系统故障或超时已如实记录；
- [ ] 没有把中途退出者强行计为完成者。
